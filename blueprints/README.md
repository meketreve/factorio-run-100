# Blueprints

Vazio por enquanto — os blueprints estão sendo montados à mão em jogo e vão ser adicionados aqui conforme ficarem prontos.

A lista do que cada um precisa conter está na seção **O livro de blueprints** da [rota](https://meketreve.github.io/factorio-run-100/).

Duas regras ao salvar:

- **Só entidades vanilla.** Blueprint com entidade de mod chega quebrado na run.
- **Blueprint de space platform é um tipo separado** e não mistura com blueprint de superfície.

A biblioteca de blueprints é global entre saves, então o que for montado num save modded aparece na run vanilla sem desativar nada.
